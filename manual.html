Versão 2.0 · Guia em linguagem simples, sem conhecimento técnico necessário

✔ Resumo de 30 segundos O Sentido Autêntico é um programa de estudo das línguas bíblicas (hebraico, aramaico e grego) que funciona sem internet. Para usar, você só precisa de duas coisas que fará uma única vez: descompactar a pasta e clicar duas vezes no arquivo de instalação do seu sistema. Este manual acompanha você em cada clique.

1O que veio no pacote

Ao descompactar o arquivo Sentido-Autentico-v2.1.zip, você verá uma pasta com estes itens principais:

ArquivoPara que serve
index.htmlO portal completo (o “programa” em si).
INSTALAR-WINDOWS.batIniciar no Windows com duplo clique.
INSTALAR-MAC-LINUX.commandIniciar no Mac ou Linux com duplo clique.
servidor.py e servidor.jsO “motorzinho” que os instaladores acionam. Você não precisa mexer neles.

⚠ Regra de ouro Nunca mova o index.html para fora da pasta. Ele precisa das pastas ao lado para funcionar — é como tirar o motor do carro: a carcaça até abre, mas não sai do lugar.

2🚀 Jeito mais fácil: o arquivo único (2 cliques)

Quer só dar uma olhada agora, sem instalar nada?

  1. Dê duplo clique no arquivo abrir-sem-servidor.html.
  2. Ele abre no seu navegador (Chrome, Edge, Firefox ou Safari) como qualquer página.
  3. Pronto! Navegue à vontade — até sem internet.
ℹ Limitação dessa versão O modo arquivo único não permite o botão “Instalar” como aplicativo nem o aviso de “offline” no canto superior. Para a experiência completa, use a instalação das próximas seções — leva 5 minutos, uma única vez.

3🪟 Instalação no Windows

Passo 1 — Instale o Python (uma vez só, é gratuito)

  1. Acesse python.org/downloads e clique no botão amarelo Download Python.
  2. Abra o instalador baixado e marque a caixinha “Add python.exe to PATH” (é a parte mais importante!).
  3. Clique em Install Now e aguarde terminar.

Passo 2 — Descompacte a pasta

  1. Clique com o botão direito no arquivo Sentido-Autentico-v2.1.zip.
  2. Escolha “Extrair Tudo…” e confirme.

Passo 3 — Inicie o portal

  1. Entre na pasta extraída e dê duplo clique em INSTALAR-WINDOWS.bat.
  2. Abrirá uma janelinha preta (o servidor local) e, em seguida, o navegador entra na página http://localhost:8080 automaticamente.
  3. Use normalmente. Enquanto estiver estudando, deixe a janelinha preta aberta (pode minimizar).
  4. Para encerrar: simplesmente feche a janelinha preta.
✔ Da próxima vez Não precisa instalar nada de novo: é só dar duplo clique no mesmo INSTALAR-WINDOWS.bat.
⚠ Se o Windows mostrar “proteção do SmartScreen” clique em “Mais informações” → “Executar assim mesmo”. O aviso aparece só porque o arquivo é novo na sua máquina; o conteúdo é seguro e offline.

4🍎 Instalação no Mac

  1. Instale o Python 3 gratuito em python.org/downloads (botão amarelo, instalação padrão — uma vez só).
  2. Dê duplo clique no .zip para descompactar.
  3. Dê duplo clique em INSTALAR-MAC-LINUX.command.
  4. Se o Mac avisar “desenvolvedor não identificado”: clique com o botão direito no arquivo → Abrir → Abrir novamente. Só precisa fazer isso uma vez.
  5. O Terminal abre e o navegador entra em http://localhost:8080. Para encerrar, feche o Terminal.

5🐧 Instalação no Linux

O Python 3 já vem instalado na maioria das distribuições (Ubuntu, Mint, Fedora…). Então:

  1. Descompacte o .zip onde preferir.
  2. Dê duplo clique em INSTALAR-MAC-LINUX.command — ou, se preferir o Terminal, rode dentro da pasta: ./INSTALAR-MAC-LINUX.command.
  3. Se o sistema pedir permissão de execução: botão direito → Propriedades → Permissões → marque “Permitir execução como programa”.
  4. O navegador abre em http://localhost:8080. Feche a janela do Terminal para encerrar.

6📲 Instalar como aplicativo (recomendado!)

Com o portal aberto (pelo servidor local), você pode “cravar” o Sentido Autêntico na tela inicial — ele vira um aplicativo de verdade, com ícone próprio, e funciona 100% sem internet a partir daí, mesmo depois de desligar o servidor.

No computador (Chrome/Edge)

Clique no botão ↓ Instalar no topo da página (ou no ícone de instalação da barra de endereços) → Instalar.

No Android (Chrome)

Abra o endereço do portal → toque nos três pontinhos ⋮ → “Instalar aplicativo” ou “Adicionar à tela inicial”.

No iPhone/iPad (Safari)

Abra o endereço do portal → toque em Compartilhar (quadrado com seta) → “Adicionar à Tela de Início” → Adicionar.

💡 No celular, onde fica o endereço do portal? O portal roda no seu computador. Para abri-lo no celular, os dois precisam estar no mesmo Wi-Fi: no computador, anote o endereço mostrado na janelinha do servidor (por exemplo http://localhost:8080 não funciona no celular — use o endereço de rede indicado junto, algo como http://192.168.0.10:8080).

8♿ Acessibilidade: o botão dourado

O círculo dourado no canto inferior direito abre a central de acessibilidade. Cada opção é salva no seu aparelho:

  • A− / A+ — aumenta ou diminui o tamanho de todas as letras.
  • Tema escuro — fundo escuro, confortável à noite.
  • Alto contraste — bordas e letras mais fortes.
  • Fonte para dislexia — mais espaçamento entre letras e palavras.
  • Ouvir página — o portal lê o conteúdo em voz alta (funciona melhor no Chrome/Edge com vozes em português).
  • Reduzir animações — desliga movimentos da tela.

9❓ Perguntas frequentes

Preciso de internet para estudar?
Não. Depois da primeira abertura (via servidor ou após instalar como app), tudo fica guardado no seu aparelho.

O portal cobra algo ou mostra anúncios?
Nunca. É gratuito, sem cadastro, sem anúncios e sem rastreamento.

Meus textos digitados nas ferramentas vão para algum lugar?
Não. Transliteração e interlinear acontecem dentro do seu navegador.

Como desinstalo?
Apague a pasta descompactada. Se instalou como aplicativo, remova-o como qualquer outro app (ícone → desinstalar).

O conteúdo pode ser usado em aulas?
Sim, livremente, com atribuição (licença Creative Commons no conteúdo e MIT no código).

10🔧 Solução de problemas

SintomaSolução
Cliquei no instalador e uma janela piscou e sumiuProvavelmente falta o Python. Instale-o (seção do seu sistema) marcando “Add python.exe to PATH”.
O navegador não abriu sozinhoDigite manualmente na barra de endereços: http://localhost:8080
“Porta em uso” ou endereço 8081, 8082…Normal: outro programa estava na 8080. Use o endereço exibido na janela do servidor.
Página em branco ou versão antiga aparecendoAtualize com Ctrl+F5 (Mac: ⌘+Shift+R) — isso limpa a memória temporária da página.
Antivírus/firewall perguntou sobre o servidorAutorize somente rede local: é o próprio portal falando com o seu navegador, sem internet.
Letras hebraicas aparecem como quadradinhosAbra uma vez com internet para baixar as fontes embutidas, ou reinstale o app; as fontes ficam gravadas depois.

11💬 Palavras técnicas explicadas de forma simples

  • Descompactar / extrair — transformar o arquivo .zip em uma pasta normal com os arquivos dentro.
  • Servidor local — um programa pequeno rodando só no seu computador, que “serve” as páginas para o seu navegador. Não é internet!
  • localhost:8080 — o endereço do seu próprio computador (a “casa” do portal na máquina).
  • PWA / “instalar como app” — tecnologia que permite instalar um site como se fosse aplicativo, funcionando offline.
  • Cache — memória temporária que o navegador usa para guardar o portal e abrir mais rápido.
