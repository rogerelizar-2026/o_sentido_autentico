# Como atualizar pelo GitHub online

1. Faça uma cópia de segurança do repositório atual pelo botão **Code > Download ZIP**.
2. Extraia o pacote integrado deste projeto em seu aparelho/computador.
3. No repositório `o_sentido_autentico`, abra a branch `main`.
4. Use **Add file > Upload files**.
5. Arraste ou selecione **todo o conteúdo interno** da pasta integrada, preservando as subpastas. Não envie a pasta externa como um único nível adicional.
6. Confirme em **Commit changes**.
7. Aguarde o GitHub Pages publicar a atualização.
8. Abra `https://rogerelizar-2026.github.io/o_sentido_autentico/` e recarregue.
9. Se o PWA instalado mostrar a versão antiga, use o aviso de atualização do portal ou feche e abra novamente. O cache foi atualizado para `v1.1.0`.
