1. Introdução - Bem-vindo à Mineração Bíblica! 🎉

Olá, estudante das Escrituras! Seja muito bem-vindo(a) ao seu novo melhor amigo para estudos bíblicos profundos. Imagine esta página como uma caixa de ferramentas antiga, daquelas cheias de instrumentos preciosos que um ourives usaria para trabalhar metais preciosos. Só que, em vez de martelos e limas, aqui você encontra gramáticas, léxicos, dicionários e comentários que vão ajudá-lo(a) a descobrir as riquezas escondidas no Hebraico, Aramaico e Grego Koiné.

Este manual foi escrito de forma simples e divertida porque acreditamos que estudar as línguas originais da Bíblia pode (e deve!) ser uma experiência emocionante, não algo complicado e chato. Vamos juntos nessa aventura?

💡 Dica: Não se preocupe se você está começando agora! Esta ferramenta foi feita tanto para iniciantes quanto para estudiosos avançados.

2. O Que É Esta Página? 🤔

A página "Ferramentas Bíblicas" é como uma biblioteca digital organizada especialmente para você que deseja mergulhar nas línguas originais das Escrituras. Ela reúne recursos cuidadosamente selecionados (como se fosse um garimpeiro escolhendo as melhores pepitas de ouro!) e os organiza de forma que você possa encontrá-los rapidamente quando precisar.

O que você vai encontrar aqui:

  • 📖 Gramáticas completas de Hebraico, Aramaico e Grego
  • 📚 Léxicos e dicionários especializados
  • 📜 Informações sobre manuscritos antigos
  • 🎧 Áudios para pronúncia correta
  • 💻 Aplicativos e softwares úteis
  • 📝 Materiais de estudo e guias práticos

3. Primeiros Passos - Começando Sua Jornada 🚀

Quando você abre a página pela primeira vez, pode aparecer uma tela de apresentação que vai te mostrar cada parte da interface. É como ter um guia turístico te mostrando os pontos principais de uma cidade nova!

  1. Observe a barra lateral esquerda: Ali você encontra o menu principal com acesso rápido às funcionalidades.
  2. Veja a barra de busca no topo: É onde você digita o que está procurando (como "léxico grego" ou "gramática hebraica").
  3. Confira os botões de filtro: Eles ajudam a separar os recursos por tipo (Gramática, Léxico, etc.).
  4. Explore os cards de recursos: Cada card é como uma "ficha" de um recurso, com título, descrição e link para acessar.
💡 Dica: Pressione a tecla ESC para sair da apresentação a qualquer momento se quiser explorar por conta própria!

4. Funcionalidades - Sua Caixa de Tesouros 💎

Agora vamos conhecer cada "ferramenta" que você tem nas mãos. Pense nelas como superpoderes para seus estudos!

🔍 4.1. Busca Inteligente

A barra de busca é sua melhor amiga quando você sabe exatamente o que quer encontrar. Digite qualquer palavra-chave, nome de autor, ou termo relacionado ao recurso que procura.

Como usar:

  • Clique na barra de busca (ou pressione / no teclado)
  • Digite sua busca (ex: "Wallace", "grego", "manuscritos")
  • Os resultados aparecem automaticamente enquanto você digita!
🪄 Busca Mágica: Clique no ícone de varinha mágica ✨ para ativar a busca inteligente que encontra recursos relacionados mesmo se você não souber o nome exato!
🏷️ 4.2. Filtros por Categoria

Os filtros são como "separadores" que organizam sua caixa de ferramentas. Em vez de revirar tudo, você escolhe ver apenas um tipo de recurso.

Categorias disponíveis:

  • Todos: Mostra tudo (padrão)
  • Gramática: Livros e materiais sobre regras das línguas
  • Léxico: Dicionários e vocabulários
  • Manuscritologia: Estudos sobre manuscritos antigos
  • Fonética: Materiais de pronúncia e áudio
  • Software: Programas e aplicativos
  • Outros: Recursos diversos

Como usar: Basta clicar no botão da categoria desejada. Clique novamente para desmarcar!

⭐ 4.3. Sistema de Favoritos (Vault)

O Vault (ou "Cofre") é onde você guarda seus recursos favoritos! É como marcar páginas num livro para voltar depois rapidamente.

Como favoritar:

  • Clique no ícone de estrela ⭐ no canto de qualquer card
  • A estrela fica dourada = recurso favorito!
  • Clique novamente para remover dos favoritos

Para ver seus favoritos:

  • No menu lateral, clique em "Meu Vault"
  • Ou use o filtro "Favoritos" na barra de filtros
⚠️ Atenção: Seus favoritos ficam salvos no SEU navegador. Se limpar os dados do navegador, eles somem! Por isso, use a função de Backup (veja abaixo).
➕ 4.4. Adicionar Novos Recursos

Encontrou um recurso incrível que não está na lista? Você pode adicioná-lo! É como contribuir com uma nova ferramenta para a comunidade.

Como adicionar:

  1. Clique no botão "+" ao lado da barra de busca
  2. Preencha o formulário:
    • Título: Nome do recurso
    • Categoria: Tipo de recurso (Gramática, Léxico, etc.)
    • Autor: Quem criou
    • Ano: Ano de publicação
    • Descrição: Para que serve
    • URL: Link para acessar/baixar
    • Tags: Palavras-chave (separe por vírgulas)
  3. Clique em "Salvar Recurso"
  4. Pronto! Seu recurso aparece na lista!
✏️ 4.5. Editar Recursos

Errou alguma informação ao adicionar? Ou quer atualizar um dado? Sem problemas! Você pode editar qualquer recurso (principalmente os que você adicionou).

Como editar:

  1. Localize o recurso que quer editar
  2. Clique no ícone de lápis ✏️ no card
  3. Altere os campos necessários
  4. Clique em "Salvar Edição"
💾 4.6. Exportar e Backup

Essa é uma das funções MAIS IMPORTANTES! Fazer backup é como tirar uma foto dos seus favoritos antes de viajar. Se algo der errado, você tem uma cópia segura!

Backup JSON (Exportar):

  • Vai até o menu lateral
  • Clica em "Backup JSON (Exportar)"
  • Baixa um arquivo .json com todos os seus favoritos
  • Guarde esse arquivo num lugar seguro (Google Drive, pendrive, email, etc.)

Restaurar Backup (Importar):

  • Vai até o menu lateral
  • Clica em "Backup JSON (Importar)"
  • Seleciona o arquivo .json que você salvou anteriormente
  • Seus favoritos voltam magicamente! ✨

Exportar em PDF:

  • Menu lateral → "Meu Vault PDF"
  • Gera um documento PDF bonito com seus favoritos
  • Perfeito para imprimir ou compartilhar!
💡 Dica de Ouro: Faça backup regularmente! Pelo menos uma vez por mês, ou sempre que adicionar vários recursos novos.

6. Dicas de Ouro para Estudo 🏆

Agora que você conhece a ferramenta, aqui vão algumas dicas para aproveitar ao máximo:

📌 Comece pelo Básico

Se você é iniciante, comece favoritando gramáticas introdutórias e léxicos básicos. Não tente começar pelos livros mais avançados logo de cara!

📚 Crie Coleções Temáticas

Use o sistema de tags para organizar seus recursos. Exemplo: adicione tags como "iniciante", "avancado", "texto-massoretico", "septuaginta" para encontrar facilmente depois.

🔄 Revise Periodicamente

A cada poucos meses, revise seus favoritos. Remova o que não usa mais e adicione novos recursos que descobriu.

👥 Compartilhe!

Exporte seu vault em PDF e compartilhe com colegas de estudo. Ensinar é uma das melhores formas de aprender!

🎯 Use a Busca Inteligente

Não sabe exatamente o que procura? Use a busca mágica (ícone de varinha ✨) para descobrir recursos relacionados ao seu tema de interesse.
